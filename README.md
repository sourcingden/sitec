# sourcingdenis / diskevich

One-page business card with two shifts:

- **Day** — `sourcingdenis`, sourcing & recruiting → LinkedIn
- **Night** — `diskevich`, DJ → SoundCloud

The round toggle in the top-right switches the shift: the background floods from the click point and the name scrambles between the two aliases. First visit picks the mode from the visitor's local time (night after 20:00); the choice is remembered afterwards.

Static, no build: just `index.html` (+ `og.png` for link previews).

Live at **https://sourcingden.github.io/sitec/**, served by GitHub Pages from `main` / root.
