How to get more out of it

  • Test one block at a time

    If a single OR-group returns nothing, the whole string will too. Start wide, then add must-haves.

  • Titles are noisy, skills are not

    On GitHub and Stack Overflow people don't have job titles — search the stack and the city instead.

  • Exclude with care

    Every NOT removes real people too. Exclude titles (recruiter, intern), not skills.

  • Rotate the angle

    If a string runs dry, change the title family or the geography rather than piling on more ANDs.
